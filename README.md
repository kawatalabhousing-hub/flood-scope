# しん水スコープ（内水氾濫 体験教材）ブラウザ版

大分地方気象台 お天気フェア（2026-10-10）用。ブラウザだけで動く AR アプリです。
同じ教材の Unity 版（`../FloodScope`）と同じ流れ・文言・見た目にそろえています。

## ファイル
| ファイル | 中身 |
| --- | --- |
| `index.html` | 共通版（iPhone / Android）。カメラ映像とジャイロで見回す仮想の通路に水を描く |
| `android.html` | Android版（WebXR / ARCore）。床を検出し、歩いても位置が合う。奥行き対応機種では本物が正しく沈む |

5つとも同じフォルダに置く。1つだけでは動かない。

## 起動してからの流れ（Unity 版と同じ）
1. **ロゴ** — 0.8 秒でフェードイン → 7 秒表示 → 0.8 秒でフェードアウト
2. **説明** — 見出し3行と説明文。下に「はじめる」「アプリをとじる」
3. **見かたをえらぶ** — 「タブレットで見る」「ゴーグルで見る」。押すとカメラの許可が出る（iPhone はセンサーの許可も）。ここから雨音が鳴る
4. **床の設定** — 「足もとの床を タップして 通路の入口を決める」
   - Android版：床に白い輪が出たら、自分の足もとの床をタップ
   - 共通版：入口に立って通路の奥を向き、画面をタップ（いま向いている方向が通路の「まっすぐ」になる）
5. **体験** — 見出し「水の深さ ◯cm」、赤い帯、右端の縦スケール、下に「設定」「終わる」
   - ゴーグルを選んでいた場合は、床を決めた時点でボタンが消えて横向きになる（縦スケールは残る）。**画面を 1.5 秒長押しで戻る**
6. **終わる** — 水位 0cm・床を解除・雨音停止 → 説明画面へ（次の人に交代。見かたも選び直す）

## 体験画面の操作
- **右端の縦スケールをなぞる** — その高さに水位が動く。目盛り（0・10・20・30・50・70）の近く ±3cm は吸いつく
- **設定** — ゴーグルで見る（戻すには画面を長押し）／水位を 0cm に戻す／音：ON・OFF／床 +1cm／床 −1cm／置き直す（床をタップし直す）／閉じる
- **リモコン**（Bluetooth キーボード／プレゼンリモコンを体験端末にペアリング。Unity 版と同じ割り当て）

| キー | 動き |
| --- | --- |
| → / PageDown / Space / Enter | 次の段階へ上げる |
| ← / PageUp | 前の段階へ下げる |
| 0 / Home | 0cm に戻す |
| 1 〜 6 | 段階を直接指定（0・10・20・30・50・70） |
| M | にごり切替（水位に連動 → 真水で固定 → 泥水で固定） |
| O | 足もとを完全に隠す ON/OFF |
| G | ゴーグルモード切替 |
| K | （共通版のみ・係員用）通路と障害物の位置合わせパネル |
| T | （共通版のみ・係員用）ゴールで止まる：ゴールから入口の方を見た向きに通路を切り替える |

にごりの固定と「足もとを隠す」は画面のボタンには無く、リモコンだけで切り替えます。
スタッフPCの操作卓（旧 desk.html）は使いません。

## 編集のしかた
- **文言を変える** → `settings.js` の `APP_TEXT`
- **水の色・にごり・水位の段階・雨・音量を変える** → `settings.js` の `WATER_SETTINGS`
- Unity 版の `AppText.asset` / `WaterSettings.asset` を変えたら、`settings.js` も同じ値にする（逆も同じ）
- 通路の寸法・障害物の位置 → `index.html` / `android.html` の `COR`
- 文字コードは UTF-8 のまま保存する。変えたら、スマホで 0 → 10 → 20 → 30 → 50 → 70 → 終わる を一度通して確認する
- GitHub のブラウザ上で鉛筆マークから編集 → Commit で自動反映。壊れたら History で前の版に戻す

## 置き方・動作条件
- GitHub Pages：Settings → Pages → Source: Deploy from a branch / main / (root)
- https のページとして直接開く（Google Sites などの「埋め込み」ではカメラが止められる）
- Android版は ARCore 対応の Android + Chrome。使えない端末では「共通版をひらく」が出る
- カメラ映像はどこにも送信・保存されません

## 会場での進め方（案内役メモ）

### 1人ずつ・5分の進め方（コーン通路 1.5m×3m）
ねらい：佐賀（2019・2021年の豪雨）や千葉（2019年の台風・大雨）の市街地で起きたような、下水道や側溝で流しきれずに道路に水があふれる「内水氾濫」を、目の前の通路で体験する。

役割：案内役（子どもの横につく）1名、操作役（リモコン）1名。体験は1人ずつ。次の子は入口の外で待つ（モニターで見学）。

1. **受付（30秒）** 案内役は探り棒（先にゴムキャップ）を渡し、「棒で探ってから一歩」「片手はバーに」を約束。
2. **開始（30秒）** 案内役が「はじめる」→ 見かたを選び、スタートマットに立って通路の奥を向き、床をタップ。子どもに渡す。
3. **水を上げて歩く（1分半）** 操作役：10 → 20。浅いうちは透明で、深くなるほど泥水に変わって足もとが見えなくなる。子どもは探りながら3m歩く（ブロック19cm → ミニコーン30cm → ミニコーン45cm）。案内役はコーンの外側を並んで歩く。
4. **ゴールで止まる（1分半）** 操作役：（共通版は T）→ 30（ブロックが消える）→ 50（30cmコーンが消える・泥水）→ 70（バーの高さ）。必要なら O で「足もとを隠す」。「こうなる前に逃げる」。
5. **ふりかえり・交代（1分）** ゴーグルを外し、コーンの白テープで「さっきの水はここまで」を実物で確認。「終わる」で次の子へ。

### 水位ごとの目安（説明用）
| 水位 | 子どもへの言葉 | 補足（大人向け） |
| --- | --- | --- |
| 10cm | くつの中に水が入る。まだ足もとは見える。 | くるぶし程度。道路の白線や段差が見えにくくなる。車はブレーキがききにくい。 |
| 20cm | 足もとが見えない！ | 子どもはひざ下。ふたが外れたマンホールや側溝への転落事故が実際に起きる深さ。傘や棒で足もとを確認。 |
| 30cm | 車のエンジンが止まるかも。 | 子どもはひざ上。地下への階段を流れ落ちる水は、大人でも上るのが困難とされる。 |
| 50cm | おとなも歩くのがむずかしい。車がうき出す。 | 歩行避難の目安は「ひざ下まで」。車は浮いて流され、ドアも水圧で開けにくい。 |
| 70cm | 大人の男の人でも歩けない。外に出ないで高いところへ。 | 成人男性の歩行限界の目安。垂直避難（2階以上）へ切り替える。 |

数値は消防庁・国土交通省などが示す一般的な目安です。流れの速さや体格で変わることを添えてください。

### 会場のつくり方（開場前・30分）
- ブース全体 約3.5m × 4m（スタッフ・見学の余白を含む）
- 床：ジョイントマットを3m×1.5m（または1.2m）に敷く。入口側の端に「スタートマット」、奥の端に「ゴールマット」を置く（テープで印でも可）。
- コーン：カットコーン（高さ70cm）を左右3本ずつ、入口から0m・1.5m・3mに置き、コーンバー1.5mでつなぐ。出口側の短辺もバーで閉じる（入口側はスタッフが立って塞ぐ）。コーンの土台に重り。床にコーンの位置をテープで印。
- コーンの白テープ：見えやすい側のコーンに10・20・30・50cmの位置で白テープを巻く。
- 障害物：入口から1.0m左寄りにスチロールブロック（100×190×390mm を横立て・19cm）、1.5m右寄りにミニコーン30cm、2.2m左寄りにミニコーン45cm。位置をテープで印（共通版はずれると画面と合わない）。
- 探り棒：閉じたビニール傘の先にゴムキャップかテニスボール。予備を1本。
- ゴーグル：カメラ穴のあるスマホ用の1眼ゴーグル、または筒型スコープ。かぶる型なら片手をバーに、スタッフが肩に手を添える。
- 体験端末：充電、自動ロックをオフ、音量を上げ、ページを開いておく。Bluetooth リモコンをペアリング。
- 位置合わせ（共通版のみ）：見かたを選んで床をタップしたあと、リモコンの K でパネルを開く。通路の幅（1.2／1.5）と障害物の種類を選び、スタートマットに立って奥を向き「いま向いている方向を『まっすぐ』にする」→ 緑の線が本物のコーンに重なるよう、目の高さ・画角・前後を調整。値は端末に保存される。
- モニター：体験端末の画面を AirPlay／Chromecast でモニターに映す（見学者用）。
- 通し確認：0 → 10 → 20 → 30 → 50 → 70 → 終わる。水が深くなるほど濁ること、ブロック・コーンが順に見えなくなることを確認。

当日のチェック：端末の充電残量、コーンとテープ印のずれ、音のON、予備の探り棒、救急用の絆創膏。

### 安全上の注意
歩くのは水位10〜30cmの間だけ、距離は3m。50cm以上は立ち止まってから。障害物は柔らかい物だけ。探り棒は振り回さず床をなでる。酔いやすい子は短く、いつでも外してよいと伝える。
